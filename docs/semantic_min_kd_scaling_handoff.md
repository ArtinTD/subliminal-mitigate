# Semantic-min KD dataset/step scaling ablation

## Authorization and scope

On September 19, 2026, after reviewing the completed 255-example/50-step
pilot, the user approved the controlled scaling ablation proposed in the task:

- nested raw teacher-data sizes 256, 512, and 1,024;
- the completed 256-response pilot reused as the first nested chunk;
- conditions `raw256_steps50`, `raw256_steps100`, `raw512_steps100`, and
  `raw1024_steps200`;
- three Trainer/data seeds per condition: 42, 43, and 44;
- fixed Unsloth adapter initialization seed 3407;
- fresh base initialization for every new student;
- the frozen 32-prompt × 4-sample evaluation protocol.

This approval does not authorize a further dataset expansion, paper-figure
update, changed teacher, benefit-based filtering, a different decoder, or an
automatic numerical success gate.

## Isolation and nesting

The completed pilot root remains immutable. The scaling root is a sibling named
`semantic_min_kd_scaling_v1`. Its chunk zero is referenced from the completed
pilot rather than copied or regenerated. Chunks one through three each contain
256 new responses generated by the same teacher and recipe. The historical
sampler receives global indices 256–1,023, so its original seed formula remains
unique over the combined nested dataset.

Selection repeats the frozen seed-0 source shuffle and extends it from 128 to
512 occurrences per source. The first 256 interleaved occurrences must exactly
match the pilot manifest. The 512- and 1,024-response datasets are strict nested
prefixes. All intact responses are retained. Only empty, malformed, or
token-limit responses are excluded, with no replacements and no benefit/cost
filtering. Actual usable counts are reported rather than relabeled as exact
post-curation sizes.

## Training comparison

The completed `raw256_steps50_seed42` run is reused. Eleven new students cover
the remaining condition/seed cells. Effective batch remains 60, LoRA rank/alpha
8/8, BF16, learning rate 2e-4, warmup 5, linear schedule, and the 2,048-token
limit. Adapter initialization remains 3407 for every run; Trainer and data-order
seeds vary together across 42, 43, and 44. This isolates seed variation without
changing the original adapter-initialization factor.

The 100- and 200-step budgets approximately preserve example exposure as raw
dataset size grows. `raw256_steps100` isolates additional optimizer steps on the
small dataset. Each run starts from the same frozen Qwen base and is evaluated
with the same historical q=1 single-model decoder.

## Execution

Use only the validated isolated runtime under the completed pilot root and one
typed L40S at a time. The launcher is
`scripts/sbatch_semantic_min_kd_scaling.sbatch`; it never submits child jobs.
Generation chunks, training adapters, evaluations, receipts, logs, and GPU
telemetry must be immutable and archived locally with hashes. Preserve partial
outputs on failure and inspect before a mechanical recovery.

The final report presents each seed separately plus seed-level means, standard
deviations, and ranges. Pooled Wilson intervals are descriptive because samples
are clustered within training seeds. No result automatically authorizes another
scale-up.
