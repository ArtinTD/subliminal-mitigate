# Data, model and rights boundaries

The EM/MASSIVE package additions contain code and experiment outcome
codes/counts, not raw training examples, generated advice or model weights.
This statement applies to the new package payload, not to a clearance of the
preserved upstream repository or its history.

- MASSIVE uses the English intent-and-slot data referenced by the paper and the
  original preparation code. The recorded upstream license is CC-BY-4.0. Obtain
  the official source with its license and attribution; use the original pinned
  source hashes/selection metadata when attempting exact input reconstruction.
- The medical training/evaluation source is the model-organism material used by
  the original experiment. Its protected archive/benign counterpart and local
  redistribution terms have not been cleared here. The paired builder accepts
  user-supplied matched data; no archive/password is bundled or downloaded.
- The EM joke bank was generated using the recorded augmentation protocol with
  source instruction prompts. The original retained bank and shard manifests
  are not fully available locally. The builder can reconstruct the procedure
  given the actual inputs; it cannot recover unavailable historical row identity.
- Qwen weights, adapter checkpoints, tokenizer blobs and source datasets must be
  acquired separately under their respective terms. MASSIVE pins
  `Qwen/Qwen2.5-7B-Instruct` at
  `bb46c15ee4bb56c5b63245ef50fd7637234d6f75`. The original EM config did not record
  an immutable revision; do not treat the MASSIVE pin as evidence of the EM pin.

Code ownership and the project source license require author/collaborator
confirmation. No existing repository license was found, so this cleanup does
not invent one. Outcome projection and path/key scans do not resolve legal rights.

See the [source map](source_map.md) for the historical source filenames to cross-check
against the shared repository. Source selection, model revisions, prompt hashes,
and dataset licenses are part of reproducibility, not incidental setup details.
